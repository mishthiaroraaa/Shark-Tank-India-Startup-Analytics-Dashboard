# Shark Tank India - Startup Analytics Board  

# Overview
An interactive 3-page Power BI dashboard analyzing 
751 startups pitched across 5 seasons of Shark Tank India, 
uncovering investment patterns, shark behavior, 
and startup ecosystem trends across India.

# Dashboard Pages
# Page 1 — Overview
- Total Startups, Total Deals, Total Investment KPIs
- Deal Success Rate (Donut Chart)
- Top Industries by Startups (Bar Chart)
- Season-wise Investment Trend (Line Chart)

# Page 2 — Shark Analysis
- Shark-wise Total Investment (Column Chart)
- Shark-wise Total Deals (Column Chart)
- Season filter (Slicer)

# Page 3 — Valuation & Insights
- Top 10 Highest Valued Startups (Bar Chart)
- Asked vs Got Valuation (Scatter Plot)
- Industry-wise Total Equity (Bar Chart)

# Key Insights
- 86.6% deal success rate across all seasons
- Food & Beverage is the most pitched industry
- Season 4 recorded highest total investment
- Beauty/Fashion is second most popular sector
